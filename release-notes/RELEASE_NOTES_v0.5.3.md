# v0.5.3

- Xbox Game Pass·게임패드 환경의 공유 코드 입력 포커스 문제를 보완했습니다.
- `Game Pass 입력 호환(공통)`을 켜면 터치 키보드 확정 후 FH6 포커스를 복구해 검색을 실행합니다.
- 숫자 입력 전 2.3초 대기를 유지하고 RC 시험의 화면 클릭 보강은 제거했습니다.
- 영향받는 환경의 RC.4 실게임 테스트에서 공유 코드 검색 진입 성공을 확인했습니다.
- 일반 키보드 환경에 영향을 주지 않도록 호환 옵션은 기본적으로 꺼져 있습니다.
- 처음에는 `챌린지만 / 런 1 / 구매·강화·삭제 0`으로 확인하세요.
